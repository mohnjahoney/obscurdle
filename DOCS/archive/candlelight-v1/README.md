# Candlelight renderer v1 archive

Archived on 2026-07-29 immediately before rebuilding Candlelight around the
single-Gaussian model in `DOCS/CANDLELIGHT-SPEC.md`.

This snapshot includes the old configuration, burn profile, shader, Phaser
mode, and tests. It preserves the former broad-pulse implementation for
reference, but the `.txt` suffixes ensure these files are not compiled.
